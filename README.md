# 🌌 Qiskit Quantum Physics

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![Qiskit](https://img.shields.io/badge/Qiskit-1.0%2B-purple.svg)](https://qiskit.org/)

Repositório dedicado à exploração de conceitos fundamentais da **Física Quântica** utilizando o **Qiskit**, o kit de desenvolvimento de código aberto da IBM para computação quântica.

---

## 🚀 Sobre o Projeto

Este projeto reúne simulações, algoritmos e experimentos teóricos convertidos em circuitos quânticos práticos. Ele serve como um laboratório virtual para conectar a teoria física à prática da programação quântica.

* Simulação de fenômenos como superposição, emaranhamento e tunelamento.
* Implementação de algoritmos quânticos aplicados a problemas de física.
* Notebooks interativos e comentados passo a passo.
